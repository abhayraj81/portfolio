## About

This repository holds the source for my personal portfolio site — a fast, vanilla HTML/CSS/JS build (no framework, no build step) styled around a dark, precision-engineering aesthetic. It's animated with **GSAP** and **ScrollTrigger**, uses **Lenis** for smooth scrolling, and is designed to load quickly while still feeling deliberate and alive.

The site covers:

- **About** — the throughline from CNC machining and instrument calibration to backend engineering
- **Toolbox** — languages, frameworks, databases, and tools grouped by where they sit in the stack
- **Experience** — an apprenticeship at the Indian Air Force Station, Kanpur, and time as a Guitar & Piano instructor at Samarpan Sangeet Kala Academy
- **Projects** — a Spring Boot REST API system and a responsive, accessibility-first NGO website
- **Credentials** — certifications and academic history
- **Contact** — direct links to email, LinkedIn, GitHub, and a downloadable résumé

## Running Locally

The site has no build step — it's static HTML, CSS, and JavaScript.

```bash
# Clone the repository
git clone https://github.com/abhayraj81/portfolio.git
cd portfolio

# Serve it with any static server, for example:
npx serve .
# or
python -m http.server 8000
```

Then open `http://localhost:8000` (or the port your server prints) in a browser.
